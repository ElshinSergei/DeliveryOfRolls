# DeliveryOfRolls

Интернет-магазин для автоматизации доставки суши и роллов.

## Технологический стек

*   **Язык:** Java 17
*   **Фреймворк:** Spring Boot 3.2.2
*   **База данных:** H2 (development), MySQL (production)
*   **Backend шаблонизатор:** Thymeleaf
*   **Frontend:** HTML5, CSS3, JavaScript (нативный)
*   **Безопасность:** Spring Security (включая HTTPS)
*   **Сборка:** Maven
*   **Дополнительно:** Lombok, Spring Data JPA, Spring Cache, Spring Mail, Scheduling, Docker

## Основные возможности

*   **Каталог товаров:** Категории и блюда, удобный интерфейс.
*   **Корзина:** Динамическое управление составом заказа.
*   **Оформление заказа:** Процесс заказа с выбором параметров доставки.
*   **Личный кабинет:** История заказов, адреса, бонусная система.
*   **Администрирование:** Панель управления товарами, заказами, акциями и промокодами.
*   **Маркетинг:** Промокоды, бонусы, email-уведомления.

## Установка и запуск

### Требования
*   JDK 17
*   Maven
*   (Для production) Docker и Docker Compose

### Локальный запуск
1.  Клонируйте репозиторий.
2.  Запустите приложение:
    ```bash
    ./mvnw spring-boot:run
    ```
